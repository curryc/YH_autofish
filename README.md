# YH_AutoFish 异环自动钓鱼脚本

一个基于 OpenCV 图像识别的《异环》自动钓鱼脚本工具。不修改游戏文件、不抓包、不利用任何漏洞，完全通过模拟正常玩家的键鼠操作实现自动钓鱼。

### 功能简介
- 自动识别鱼漂/提示图标并进行抛竿、收杆
- 支持连续自动钓鱼，解放双手
- 所有操作均为模拟键鼠输入，尽量降低封号风险（风险仍然存在，请自行评估）

### 运行环境
- **操作系统**: Windows 11
- **Python**: 3.10+（作者使用3.14版本
- **依赖库**: 主要依赖 OpenCV 等，在首次运行前请通过requirements.txt先安装依赖

### 使用方法
0. 下载地址：[密码：yhnb](https://wwblf.lanzouu.com/b01bjdsoeh)
1. 启动游戏，并将游戏分辨率设置为 **1280x720**（窗口化）。
2. 按照需求更改config.py，比如：等待时间，是否自动关机等
3. 运行exe，程序会请求以**管理员身份**运行，同意后开始钓鱼
4. 遇到bug欢迎在issues里面交流谢谢喵~
